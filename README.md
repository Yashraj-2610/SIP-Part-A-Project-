# 🚗 Car Price Prediction

A machine learning project that predicts car prices using various vehicle features.

## 📌 Project Overview

This project explores a car-price dataset and builds a machine learning model
to predict the price of a vehicle based on its available features.

## 🔍 Workflow

- Data loading
- Data cleaning
- Exploratory Data Analysis
- Feature preprocessing
- Model training
- Model evaluation
- Performance comparison

## 📊 Results

| Model | RMSE |
|---|---:|
| Baseline | 1,587,725 |
| Final Model | 1,175,221 |

The final model achieved a lower RMSE than the baseline model.
